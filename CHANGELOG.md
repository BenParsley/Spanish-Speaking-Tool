# Changelog

## 2026-11-25

### New
- Added a Debug Mode toggle switch at the top of Settings that disables all tracking/saving and displays a repeated `DEVELOPMENT` background watermark behind `#view-play`.
- Added free one-click stage switching (`Go →`) across all units in the Guidebook while preserving each stage's progress.
- Added a full-answer bonus visual and audio reward when optional phrase variants are included.
- Added a pinned active model badge (`Hybrid` / `Browser`) to the bottom-right Console button and panel.

### Updated
- Moved Daily Goal and Time Spent into the top header, horizontally aligned side-by-side and centered between the title and Settings button.
- Updated question scoring so only the base phrase is required, highlighting optional variants in soft pastel yellow and tracking them in mastery when included.
- Updated Pronunciation Engine to always reset to Local Hybrid on page load/refresh while keeping in-session switches active.
- Fixed active phrase resolution so previous prompt text no longer drops variant highlights or mismatches memory tips.
- Removed the Session Summary feature and all settings, data management, and QA testing tools below Pronunciation Engine along with their associated code.
